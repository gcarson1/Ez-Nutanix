# Cloud provider logos

Shown on the landing slide's public-cloud block, as on the original Nutanix slide. They are the
providers' trademarks, used only to name where the platform runs. From Wikimedia Commons, 2026-10-19:

- `aws.svg`: https://upload.wikimedia.org/wikipedia/commons/9/93/Amazon_Web_Services_Logo.svg
- `azure.svg`: https://upload.wikimedia.org/wikipedia/commons/f/fa/Microsoft_Azure.svg
- `google-cloud-icon.svg`: the four colored cloud shapes from https://upload.wikimedia.org/wikipedia/commons/5/51/Google_Cloud_logo.svg, without the wordmark (paths and colors unchanged, viewBox cropped to the mark)
